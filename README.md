# CaryLabs Skills

Reusable Codex skills maintained by CaryLabs.

## Available skills

- [`model-review-skill`](skills/model-review-skill): request structured,
  read-only engineering reviews from native Claude or Gemini APIs and any
  OpenAI-compatible cloud or local model endpoint. Copy the skill directory into
  your Codex skills directory, then create the documented local configuration in
  the repository being reviewed.

  - [中文用户手册（零开发基础版）](docs/model-review-skill-user-guide.zh-CN.md)
